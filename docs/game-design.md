# ゲームデザイン

花嫁もぐもぐチャレンジの画面の流れと遊び方のルール。得点の計算は [scoring.md](scoring.md)、振り子と食べ物の動きは [physics.md](physics.md) を参照。

画面はすべて横向き（844×390 の論理座標）で、縦向きのときは「端末を横向きにしてください」と表示する。

## 画面の流れ

```
タイトル ──(?)──> 遊び方（3ページ: ① 操作方法 → ② 高得点のコツ → クレジット）
   │ TAP TO START
   ▼
位置決め ──(スタート)──> カウントダウン ──> プレイ（20秒） ──> リザルト
   ▲                                          │                    │
   └──────────── リトライボタン / もう一度 ─────┘◀───────────────────┘
                                               タイトルへ ──> タイトル
```

| 画面 | 内容 |
|---|---|
| タイトル | 画面のどこかをタップすると開始。右上の「?」で遊び方を開く |
| 遊び方 ① | 本物のゲームを半分の大きさで遊べるデモ。時間は無制限で、新婦と食べ物の当たり判定の円を表示する。触るまでドラッグの手のアニメーションを出し、触らずに 5 秒たつとまた出す |
| 遊び方 ② | 高得点のコツ（好物の点数、連続ボーナス、プレイ回数ボーナス）のカード |
| クレジット | 制作者（制作: Jumpei Kurokawa）と見守り（Yuria Otsuka）、効果音・BGM・画像・フォントの出どころ（表になっている）。下に「プレイ結果は、ランキングのために記録されます」。内容は `lib/app/how_to_play_credits.dart` の `creditGroups`、出どころの詳細は [assets.md](assets.md#出典とクレジット) |

遊び方の 3 ページは、右下の ▶ で次へ、◀ で前へ進む。▶ は常に同じ位置にあり、◀ はその左に並ぶ。最後のクレジットでは、◀ だけが、▶ のあった位置より少し左に出る（ずらす量は `lib/app/how_to_play_popup.dart` の `_lastBackShift`）。右上の × で、どのページからでも閉じられる。
| 位置決め | 支点（振り子の関節）と新婦をドラッグして、振り子の初期位置を決める。どちらも 360° 回せる。右上にプレイ回数ボーナスのゲージ |
| カウントダウン | 3, 2, 1, START（START は 0.8 秒）。この間は何も動かない |
| プレイ | 20 秒間、振り子が動き、食べ物を投げられる |
| リザルト | 今回のスコアと全試行中の順位、自己ベストと挑戦者中の順位。自己ベストを更新すると「New Record」 |

## 操作

- **位置決め:** 関節（支点の丸）か新婦をつかんで回す。手を離した位置からスタートする。スタート時に振り子へ一定のエネルギーが与えられ、勢いよく動き出す（[physics.md](physics.md)）。
- **投げる:** 画面のどこからでもドラッグを始め、引っぱった方向と**反対向き**に投げる（パチンコの要領）。引っぱる間は予測軌道のガイドが出る。12 px 未満のドラッグは投げずに取り消し。
- 食べ物は一度に 1 個だけ。新婦が食べるか、画面の左右・下へ出ると、新郎の手元に次の食べ物が出る。

## ルール

- 新婦の顔のあたりの当たり判定の円に食べ物が触れると、新婦が食べて得点になる（[physics.md](physics.md#当たり判定)）。
- 続けて食べさせると連続ボーナスが付き、外す（食べ物が画面外へ出る）と途切れる（[scoring.md](scoring.md)）。
- 食べ物は 20 種類。新婦の好物ほど点数が高く、同じ ID で遊んだ回数が多いほど好物が出やすい（[scoring.md](scoring.md)）。
- **ブザービーター:** 時間切れの時点で飛んでいる食べ物は、そのまま最後まで飛び、食べられれば得点になる。時間切れ後は新しく投げられない。
- プレイ中のリトライボタンで途中でやめると、同じ振り子の位置で位置決めからやり直す。やめたゲームは記録しない。
- リザルトの「もう一度」も、前回と同じ振り子の位置から始まる。

## 音

- 画面の**左下**に、音の ON/OFF ボタンが全画面で出る（タイトル、遊び方、位置決め、カウントダウン、プレイ、リザルト）。BGM と効果音をまとめて切り替える。
- 起動時は **OFF**。ブラウザは、ユーザーが操作するまで音を鳴らせないので、最初にボタンを押して ON にしたときに BGM が始まる。設定は覚えず、読み込み直すと OFF に戻る。
- 状態は、アイコン（ON は音波付きのスピーカー、OFF はうすい色のスピーカーと ✕）と、文字（ON / OFF）の 2 つで分かる。色は、ほかのボタンのアイコンと同じ濃い茶色。
- **BGM** は最後まで再生すると最初から繰り返し、画面が変わっても途切れない。
- 一度始まった BGM は、OFF にしても止まらず、**裏で流れ続けている**ことにする。もう一度 ON にすると、最初からではなく、そのときに流れているはずの場所から聞こえる。
- アプリが裏に回る（タブを切り替えるなど）と一時停止し、戻ると再開する。
- **効果音:** 食べ物を投げたとき（ドラッグを離した瞬間）と、新婦が食べたとき。食べ物が場外へ出たとき、新しい食べ物が出たときは鳴らさない。
- **ホイッスル:** カウントダウンの「START」が出た瞬間に 1 回。
- **拍手:** リザルト画面が出た瞬間に 1 回。最後の食べ物のスコア演出を待ってからリザルトが出るので、拍手もそのときに鳴る（ゲームが終わった瞬間ではない）。約 3 秒続くが、リザルトの「もう一度」「タイトルへ」を押すと、その場で止まる。
- 遊び方①のデモでは、投げる音と食べる音は鳴るが、カウントダウンもリザルトもないので、ホイッスルと拍手は鳴らない。

## 演出

- 新婦が食べると、口元に連続数分のハート（5 連続ごとに大きなハート 1 つにまとめる）、「+点数」、「3COMBO ×1.4」の形の連続表示が出る。
- 投げると新郎が投げる動きをする（見た目だけで、食べ物はドラッグを離した瞬間に飛ぶ）。
- 時間切れ間際に食べた場合は、得点の演出が終わってからリザルトを出す。
